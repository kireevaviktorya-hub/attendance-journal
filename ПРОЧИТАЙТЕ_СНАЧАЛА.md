# Электронный журнал посещаемости — публикация на GitHub Pages

Сайт подключён к проекту Supabase `attendance-journal`. Таблица `teacher_journals`, права для `authenticated`, запрет для `anon` и политика Row Level Security уже настроены.

## Остался один шаг — включить GitHub Pages

1. Откройте Settings → Pages в репозитории `attendance-journal`.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
4. Дождитесь ссылки GitHub Pages. Ожидаемый адрес: `https://kireevaviktorya-hub.github.io/attendance-journal/`.

Файлы `index.html`, `config.js` и `.nojekyll` должны оставаться в корне репозитория. SQL повторно запускать не нужно.

## Защита данных

В коде используется только Supabase Publishable key. Не публикуйте Secret/service_role key, пароли базы, резервные копии JSON и CSV с данными учеников. RLS ограничивает доступ к строке журнала аккаунтом-владельцем.
